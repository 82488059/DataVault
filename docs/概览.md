# DataVault / 数据管理 — 项目概述

## 一句话介绍

**DataVault（数据管理）** 是一款基于 **Tauri 2** 的桌面应用，用于在本机以资源管理器方式浏览磁盘、将选定文件/文件夹备份到目标硬盘，并通过 **完整 MD5** 与 **抽样 MD5** 校验备份完整性。

## 核心能力

| 能力 | 说明 |
|------|------|
| 资源管理器式浏览 | 列出盘符、文件夹、文件；进入/返回；多选 |
| 备份到目标盘 | 将选中项复制到用户指定的目标目录，并写入元数据 |
| 完整 MD5 | 对整文件计算 MD5，用于严格校验 |
| 抽样 / 快速 MD5 | 取文件头尾各 64KB 及文件大小参与摘要 |
| 校验 UI | 「完整校验」与「快速校验」 |

## 技术栈

Tauri 2 + Vue 3 + TypeScript + Rust；元数据为本地 JSON。
