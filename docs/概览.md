# DataVault / 数据管理 — 项目概述

## 一句话介绍

**DataVault（数据管理）** 是一款基于 **Tauri 2** 的桌面应用：主窗口以资源管理器方式浏览本机磁盘，并直接完成**备份、受控登记/索引与校验**；长任务在下方**多任务状态面板**异步展示（含当前文件进度），校验结果可按**通过 / 失败 / 缺失 / 错误**四态筛选。

## 适用场景

- 备份拷贝后的完整性确认（完整 MD5 / FastMD5）
- 受控盘标记与备份索引，明确「哪些文件纳入管理」
- **移动硬盘长时间不通电存放后再接上使用**：可能出现静默损坏（文件仍在、大小正常，内容已坏），凭打开文件不易发现；用事先登记的校验值做完整性核对，适合归档盘 / 冷备盘重新启用前的排查

## 窗口分工

| 窗口 | 职责 |
|------|------|
| **主窗口** | 浏览；**标记为受控**（盘符根）；批次备份；**建立备份索引**（勾选路径，合并原「添加受控」）；范围/受控/批次校验；下方**状态**面板；入口打开高级校验 / 高级备份 |
| **高级校验** | 独立窗：按目录校验受控项 + 批次表（批次号/时间/文件数/盘符）；多选快速/完整校验；结果四态 |
| **高级备份** | 独立窗：左右**等宽**双栏（左多选源、右单选目标）；可选批次名称、**文件名正则**（匹配/排除；裸正则或 `/pattern/flags`）、**打包为 tar**；可展开受控 `.tar`；长文件名换行 |

## 核心能力

| 能力 | 说明 |
|------|------|
| 资源管理器式浏览 | 列出盘符、文件夹、文件；进入/返回；多选；不展示 .datavault |
| 列表列 | **名称 / 大小 / 受控 / 数量**（目录数量为「受控文件数/总文件数」，异步填充）；已去掉「类型」「标记」列；名称列长路径**换行**（非省略号截断） |
| 受控盘标记 | 仅可在盘符根标记；盘根 `.datavault/disk.json` 标识；UI 文案统一为**受控盘 / 标记为受控**（底层仍 `is_backup_disk`） |
| 受控文件清单 | `.datavault/vault.db` 表 `controlled_files`；绿色「受控」徽章 |
| 批次备份 | 复制到目标目录并写批次元数据；可选批次名称（默认本地 `YYYYMMDDHHmmss`） |
| 完整 MD5 | 整文件 MD5，用于严格校验 |
| FastMD5 | 每块（默认 100MB）取前 10%（含余块）再汇总 MD5 |
| 建立备份索引 | **单一按钮**（合并原添加受控）：勾选路径则索引所选；可自动标记未受控盘；**跳过已受控**，不重复算哈希 |
| 范围校验 | 主窗口按所选目录/文件解析到已受控项后再校验；盘符列表勾选受控盘=该盘全部受控 |
| 多任务状态面板 | 主窗下方「状态」：并行任务列表；中文任务名（备份 / 登记受控 / 完整校验 / 快速校验 / 批次完整校验 / 批次快速校验 等）；展开显示进度条、**当前文件**、取消；完成后内嵌校验摘要 |
| 校验四态 | 批次与受控校验统一：**通过 / 失败 / 缺失 / 错误**（`pass` / `fail` / `missing` / `error`），计数可点击筛选 |
| 高级备份过滤 | 源**文件名**正则：匹配或排除；支持裸 Rust 正则（如 `\.pdf$`）或 JS 风格 `/pattern/flags`（`i`/`m`/`s`/`x`；`g`/`u`/`y` 忽略） |
| 打包 tar | 可选将选中文件打成 `{批次ID}.tar`；目标为受控盘时自动登记归档到 `vault.db`；浏览器可双击展开已受控 `.tar` |
| 异步任务 | 索引/备份/校验后台执行并发出进度事件；UI 不卡死；少用瞬时横幅，以状态面板为准 |
| 悬停提示 | 主要按钮使用 `title` 中文 tooltip |

## 技术栈

Tauri 2 + Vue 3 + TypeScript + Rust；多窗口用 WebviewWindow；备份盘元数据为 **JSON（disk.json）+ SQLite（vault.db）**。
