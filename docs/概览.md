# DataVault / 数据管理 — 项目概述

## 一句话介绍

**DataVault（数据管理）** 是一款基于 **Tauri 2** 的桌面应用：主窗口以资源管理器方式浏览本机磁盘；**备份**与**校验**分别在独立小窗口中完成，避免主界面被长任务占用。

## 窗口分工

| 窗口 | 职责 |
|------|------|
| **主窗口** | 文件浏览（盘符/目录/多选）；隐藏 .datavault；标记备份盘；打开「备份」「校验」窗口 |
| **备份窗口** | 选择源与目标、开始备份（批次）；添加受控文件；建立备份索引；进度与结果 |
| **校验窗口** | 受控文件完整/快速校验、备份批次完整/快速校验及结果展示 |

## 核心能力

| 能力 | 说明 |
|------|------|
| 资源管理器式浏览 | 列出盘符、文件夹、文件；进入/返回；多选；不展示 .datavault |
| 备份盘标记 | 盘根 .datavault/disk.json 标识备份盘 |
| 受控文件清单 | .datavault/vault.db 表 controlled_files |
| 批次备份 | 复制到目标目录并写批次元数据 |
| 完整 MD5 | 整文件 MD5，用于严格校验 |
| FastMD5 | 每块（默认 100MB）取前 10%（含余块）再汇总 MD5 |
| 异步任务 | 索引/登记/备份/校验在后台线程执行并发出进度事件，UI 不卡死 |
| 悬停提示 | 主要按钮使用 	itle 中文 tooltip；批次校验提示**不含**「头/尾 64KB 旧路径」说明 |

## 技术栈

Tauri 2 + Vue 3 + TypeScript + Rust；多窗口用 WebviewWindow；备份盘元数据为 **JSON（disk.json）+ SQLite（vault.db）**。
