# DataVault / 数据管理 — 项目概述

## 一句话介绍

**DataVault（数据管理）** 是一款基于 **Tauri 2** 的桌面应用：资源管理器式浏览本机磁盘，将目标盘标记为**备份盘**，登记**受控文件**到盘上 SQLite，并通过 **完整 MD5** 与 **FastMD5（分块抽样）** 校验完整性。

## 核心能力

| 能力 | 说明 |
|------|------|
| 资源管理器式浏览 | 列出盘符、文件夹、文件；进入/返回；多选 |
| 备份盘标记 | 盘根 `.datavault/disk.json` 标识备份盘 |
| 受控文件清单 | `.datavault/vault.db` 表 `controlled_files` |
| 完整 MD5 | 对整文件计算 MD5，用于严格校验 |
| FastMD5 | 每块（默认 100MB）取前 10%（含余块）再汇总 MD5 |
| 校验 UI | 「完整校验」与「快速校验」对照数据库 |

## 技术栈

Tauri 2 + Vue 3 + TypeScript + Rust；备份盘元数据为 **JSON（disk.json）+ SQLite（vault.db）**。
