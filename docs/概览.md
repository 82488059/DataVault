# DataVault / 数据管理 — 项目概述

## 一句话介绍

**DataVault（数据管理）** 是一款基于 **Tauri 2** 的桌面应用：主窗口以资源管理器方式浏览本机磁盘；**备份**与**校验**分别在独立小窗口中完成，避免主界面被长任务占用。

## 窗口分工

| 窗口 | 职责 |
|------|------|
| **主窗口** | 文件浏览（盘符/目录/多选）；隐藏 .datavault；标记备份盘；**显示是否已受控**；打开「备份」「校验」（可带勾选路径） |
| **备份窗口** | 选择源与目标（**勾选目录可设为目标**；列表**全选/取消全选**）、开始备份（批次）；添加受控 / 建立索引（**已受控跳过重哈希**）；进度与结果 |
| **校验窗口** | **按目录/文件限定范围**（工具栏单行；列表下方快速/完整校验），仅校验 vault.db 已受控项；批次校验及结果 |

## 核心能力

| 能力 | 说明 |
|------|------|
| 资源管理器式浏览 | 列出盘符、文件夹、文件；进入/返回；多选；不展示 .datavault |
| 备份盘标记 | 仅可在盘符根标记；盘根 .datavault/disk.json 标识备份盘 |
| 受控文件清单 | .datavault/vault.db 表 controlled_files；UI 显示受控状态 |
| 批次备份 | 复制到目标目录并写批次元数据；目标可用勾选目录指定 |
| 完整 MD5 | 整文件 MD5，用于严格校验 |
| FastMD5 | 每块（默认 100MB）取前 10%（含余块）再汇总 MD5 |
| 增量登记/索引 | 添加受控、建立索引时**跳过已受控文件**，不重复算哈希 |
| 范围校验 | 按所选目录/文件解析到已受控项后再校验；未受控不列入 |
| 异步任务 | 索引/登记/备份/校验在后台线程执行并发出进度事件，UI 不卡死 |
| 悬停提示 | 主要按钮使用 title 中文 tooltip；批次校验提示**不含**「头/尾 64KB 旧路径」说明 |

## 技术栈

Tauri 2 + Vue 3 + TypeScript + Rust；多窗口用 WebviewWindow；备份盘元数据为 **JSON（disk.json）+ SQLite（vault.db）**。
