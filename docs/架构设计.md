# 架构设计

## 结构

```text
主窗口 (label=main)
  ├── 浏览 / 标记备份盘
  ├── 批次备份 · 受控登记 · 建立索引
  ├── 范围 / 受控 / 批次校验
  └── 校验结果独立面板
         │
Vue 前端 ──invoke──► Rust 命令
                      ├── 文件系统浏览 / 复制
                      ├── .datavault/disk.json + vault.db
                      ├── 完整 MD5 / FastMD5
                      └── 后台 Job（线程 + emit 进度/完成）
```

## 多窗口

| Label | 前端入口 | 说明 |
|-------|----------|------|
| `main` | `MainApp.vue` | 唯一窗口：浏览、备份、受控/索引（**须先勾选**）、范围/受控/批次校验、**结果独立面板** |
| ~~backup~~ / ~~verify~~ | 已废弃 | 独立窗口已取消，逻辑并入 `MainApp.vue` |

- 前端 `src/main.ts` 仅挂载 `MainApp`。
- Capability：`windows: ["main"]`。

## 异步 Job

| 任务 | 事件（示例） | 所在窗口 | 备注 |
|------|--------------|----------|------|
| 添加受控 / 全盘索引 | `controlled-job-progress` / `controlled-job-finished` | 主窗口 | **跳过 vault.db 已有项**，不计重复哈希；`skipped` 计入完成消息 |
| 批次备份 | `backup-job-progress` / `backup-job-finished` | 主窗口 | |
| 受控/批次校验 | `verify-job-progress` / `verify-job-finished` | 主窗口 | 受控校验可按 `rel_paths` 或绝对 `paths` 过滤 |

UI 订阅事件更新进度条与结果，不阻塞主线程。

## 命令（摘要）

浏览：`list_drives`、`list_dir`（过滤 `.datavault`；返回 `is_controlled`：文件精确匹配，目录为「其下存在受控文件」）  
备份盘：`mark_backup_disk`（**仅接受盘符根**如 `E:\`，拒绝子目录）、`detect_backup_disks`  
受控：`start_add_controlled_files`、`start_index_backup_disk`、`cancel_controlled_job`、`list_controlled_files`、`resolve_controlled_selection`（绝对路径 → 仅已受控）  
校验：`start_verify_controlled`（`rel_paths` / `paths` 可选）、`verify_controlled_full` / `verify_controlled_quick`、`verify_backup` / `start_verify_backup`、`cancel_verify_job`  
备份：`start_backup` / `backup_paths`、`cancel_backup_job`

## 关键行为（本批）

1. **校验范围**：用户勾选目录/文件 → `resolve_controlled_selection` → 只保留 vault.db 中的 `rel_path`；未受控静默丢弃。
2. **受控标记**：`list_dir` 填充 `is_controlled`，主窗口与备份窗口列表展示「受控」徽章。
3. **跳过重哈希**：`job::run_hash_job` / 同步 `add_controlled_files` 在哈希前过滤已存在 `rel_path`。
4. **目标目录**：备份窗「设为目标目录」优先取**勾选的唯一目录**，否则用当前浏览路径。

## 主窗口布局

左侧浏览；右侧侧栏为备份批次、受控/索引、校验操作；**下方专用「校验结果」面板**展示通过/失败/缺失/错误列表，不与浏览/操作区混排。添加受控与建立索引在未勾选时禁用。

## UI 提示约定

主要按钮使用 `title` 中文悬停提示。批次校验相关提示**不**描述头/尾 64KB 旧算法。
