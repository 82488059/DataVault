# 架构设计

## 结构

Vue 3 前端 --invoke--> Rust Tauri 命令 --> 文件系统 / JSON 元数据

## 命令

list_drives, list_dir, backup_paths, md5_full, md5_quick, verify_backup, list_batches, load_batch

## 元数据

- {app_data}/DataVault/metadata/batches/{id}.json
- {dest}/.datavault/{id}.json

## 抽样 MD5

头/尾 64KiB（按大小规则）+ ascii(size) → MD5；完整 MD5 仅字节流。
