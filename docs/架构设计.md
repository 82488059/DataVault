# 架构设计

## 结构

```text
主窗口 (label=main)     ──打开──► 备份窗口 (label=backup)
        │                              │
        └──打开──► 校验窗口 (label=verify)
                │
Vue 前端 ──invoke──► Rust 命令
                      ├── 文件系统浏览 / 复制
                      ├── .datavault/disk.json + vault.db
                      ├── 完整 MD5 / FastMD5
                      └── 后台 Job（线程 + emit 进度/完成）
```

## 多窗口

| Label | 前端入口 | 说明 |
|-------|----------|------|
| `main` | `MainApp.vue` | Tauri 默认窗口；浏览与入口 |
| `backup` | `BackupApp.vue` | `WebviewWindow` 动态创建；备份/受控/索引 |
| `verify` | `VerifyApp.vue` | `WebviewWindow` 动态创建；校验与结果 |

- 前端用 `getCurrentWebviewWindow().label` 挂载对应组件（`src/main.ts`）。
- 打开前经 `localStorage` + 全局事件传递上下文（源路径、盘符、受控勾选等）。
- Capability：`windows: ["main","backup","verify"]`，并授予 `core:webview:allow-create-webview-window`。

## 备份盘元数据

```text
<drive>/.datavault/disk.json
<drive>/.datavault/vault.db   # controlled_files
```

规格：[2026-09-28-backup-disk-controlled-files-design.md](./superpowers/specs/2026-09-28-backup-disk-controlled-files-design.md)

## 批次元数据（备份复制）

- 应用数据目录 `metadata/batches/batch-*.json`
- 目标旁路 `.datavault/batch-*.json`（浏览时隐藏该目录）

## 异步 Job

| 任务 | 事件（示例） | 所在窗口 |
|------|--------------|----------|
| 添加受控 / 全盘索引 | `controlled-job-progress` / `controlled-job-finished` | 备份窗口 |
| 批次备份 | `backup-job-progress` / `backup-job-finished` | 备份窗口 |
| 受控/批次校验 | `verify-job-progress` / `verify-job-finished` | 校验窗口 |

UI 订阅事件更新进度条与结果，不阻塞主线程。

## 命令（摘要）

浏览：`list_drives`、`list_dir`（过滤 `.datavault`）  
备份盘：`mark_backup_disk`、`detect_backup_disks`  
受控：`start_add_controlled_files`、`start_index_backup_disk`、`cancel_controlled_job`、`list_controlled_files`  
校验：`verify_controlled_full` / `verify_controlled_quick`（或异步 start_*）；`verify_backup` / `start_verify_backup`  
备份：`backup_paths` 或 `start_backup`  

## UI 提示约定

主要按钮使用 `title` 中文悬停提示。批次校验相关提示**不**描述头/尾 64KB 旧算法。
