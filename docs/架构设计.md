# 架构设计

## 结构

```text
Vue 3 前端 --invoke--> Rust Tauri 命令
                         |-> 文件系统（浏览 / 复制）
                         |-> 备份盘 .datavault/disk.json
                         |-> 备份盘 .datavault/vault.db（SQLite）
                         |-> 完整 MD5 / FastMD5
```

## 备份盘元数据（已批准设计）

盘根：

```text
<drive>/.datavault/disk.json   # is_backup_disk, app, created_at, updated_at
<drive>/.datavault/vault.db    # controlled_files
```

`controlled_files` 主键 `rel_path`；字段含 `size`、`mtime`、`md5`、`fast_md5`、`sample_ratio`（默认 0.10）、`sample_chunk_mb`（默认 100）、`updated_at`。

规格全文：[2026-09-28-backup-disk-controlled-files-design.md](./superpowers/specs/2026-09-28-backup-disk-controlled-files-design.md)

## 命令（现状 + 规划）

**已有（脚手架）**：`list_drives`, `list_dir`, `backup_paths`, `md5_full`, `md5_quick`, `verify_backup`, `list_batches`, `load_batch`

**规划（受控文件）**：`mark_backup_disk`、扩展盘符检测、`add_controlled_files`、`list_controlled_files`、`verify_controlled_full`、`verify_controlled_quick`（名称以实现为准）

## 哈希

| 算法 | 用途 | 规则 |
|------|------|------|
| 完整 MD5 | 严格校验 | 整文件字节流 |
| FastMD5 | 快速校验 | 每 100MB（可配）块取前 10%（可配），含余块；参数入库 |

## 历史说明

早期批次元数据（`{app_data}/DataVault/metadata/batches/`、目标旁路 `.datavault/batch-*.json`）与头尾 64KiB 抽样仍存在于脚手架代码中；**受控文件路径以本设计的 SQLite + FastMD5 为准**。兼容或废弃在实现阶段单独处理。
