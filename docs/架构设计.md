# 架构设计

## 结构

```text
主窗口 (label=main)
  ├── 浏览 / 标记为受控（盘符根）
  ├── 批次备份 · 建立备份索引（合并）
  ├── 范围 / 受控 / 批次校验
  └── 多任务「状态」面板（进度 + 四态结果）
         │
Vue 前端 ──invoke──► Rust 命令
                      ├── 文件系统浏览 / 复制
                      ├── .datavault/disk.json + vault.db
                      ├── 完整 MD5 / FastMD5
                      └── 后台 Job（线程 + emit 进度/完成）
```

## 多窗口

| Label | 前端入口 | 说明 |
|-------|----------|------|
| `main` | `MainApp.vue` | 浏览、备份、统一「建立备份索引」、校验、**状态面板**；入口打开高级校验/高级备份 |
| `batches` | `BatchManageApp.vue` | 高级校验：按目录 + 批次表；多选快速/完整；四态结果 |
| `adv-backup` | `AdvancedBackupApp.vue` | 高级备份：左多选源、右单选目标；正则过滤；可选打包 tar；展开受控 tar |

- 前端按窗口 label 挂载对应 App。
- Capability：需覆盖 `main` / `batches` / `adv-backup`。

## 备份盘元数据

```text
<drive>/.datavault/disk.json
<drive>/.datavault/vault.db   # controlled_files
```

规格：[2026-09-28-backup-disk-controlled-files-design.md](./superpowers/specs/2026-09-28-backup-disk-controlled-files-design.md)

UI 称「受控盘」；字段仍为 `is_backup_disk`。

## 批次元数据（备份复制）

- 应用数据目录 `metadata/batches/<批次ID>.json`（默认 ID = 本地 `YYYYMMDDHHmmss`，可自定义名称）
- 目标旁路 `.datavault/<批次ID>.json`（浏览时隐藏该目录）

## 异步 Job

| 任务 | 事件（示例） | 所在窗口 | 备注 |
|------|--------------|----------|------|
| 建立备份索引（勾选路径 / 全盘） | `controlled-job-progress` / `controlled-job-finished` | 主窗口 | **跳过 vault.db 已有项**；`skipped` 计入消息；UI 标签「登记受控」等 |
| 批次备份 | `backup-job-progress` / `backup-job-finished` | 主窗口 / 高级备份 | |
| 受控/批次校验 | `verify-job-progress` / `verify-job-finished` | 主窗口 / 高级校验 | 条目 `status`: pass/fail/missing/error；汇总 `passed/failed/missing/errors` |
| 目录文件计数 | `dir-file-counts`（及 job 完成） | 主窗口 / 高级窗 | 填充「数量」列 |

UI 在「状态」面板订阅事件：中文 `kind` 标签、`phase` 中文、当前 `rel_path`、可取消；完成后展开四态筛选。

## 命令（摘要）

浏览：`list_drives`、`list_dir`（过滤 `.datavault`；`is_controlled`；可选计数字段）、`start_dir_file_counts`  
受控盘：`mark_backup_disk`（**仅盘符根**）、`detect_backup_disks`  
受控：`start_add_controlled_files`、`start_index_backup_disk`、`cancel_controlled_job`、`list_controlled_files`、`resolve_controlled_selection`  
校验：`start_verify_controlled`、`verify_controlled_full` / `verify_controlled_quick`、`verify_backup` / `start_verify_backup`、`cancel_verify_job`  
备份：`start_backup` / `backup_paths`（可选 `name_regex` / `regex_exclude` / `pack_as_tar`）、`list_tar_entries`、`cancel_backup_job`

## 关键行为（本批）

1. **校验范围**：`resolve_controlled_selection`；勾选受控盘符根 → 全盘受控。
2. **受控标记 / 数量列**：`list_dir.is_controlled` + 异步目录计数；列：**名称 / 大小 / 受控 / 数量**。
3. **跳过重哈希**：索引前过滤已有 `rel_path`。
4. **目标目录**：勾选唯一目录优先，否则当前路径。
5. **批次校验四态**：与受控校验对齐 `pass|fail|missing|error`（不再仅用 boolean `ok`）。
6. **状态面板**：替代分散瞬时横幅；多 job 并行展示。

## 主窗口布局

左侧浏览；右侧侧栏为校验（含高级校验入口）、备份（含高级备份入口）、建立备份索引；**下方「状态」面板**展示任务与校验明细。

## UI 提示约定

主要按钮使用 `title` 中文悬停提示。不描述头/尾 64KB 旧算法。产品文案优先「受控 / 受控盘 / 标记为受控」。
