## 主窗口职责

1. 文件浏览（盘符 / 目录 / 多选）；隐藏 `.datavault`；标记备份盘（仅盘符根）
2. 显示是否已受控
3. **备份批次**：设源 / 设目标 / 开始备份（异步）
4. **添加受控文件**：须先勾选文件/目录。**建立备份索引**：进入备份盘或勾选备份盘符即可（无需内部勾选）。两按钮同一行；已受控跳过重哈希
5. **校验**：直接用当前勾选（仅已受控；未勾选=全部）；盘符列表勾选备份盘符亦可（=该盘全部受控；非备份盘不启用）；批次校验；异步可取消。无「应用到校验范围 / 清除范围」
6. **校验结果独立面板**（主窗下方专用区域，不与浏览/操作区混排）
7. **取消任务**与进度条同区显示（不放顶栏工具栏）
