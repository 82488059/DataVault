# 多窗口：备份 / 校验独立小窗口

日期：2026-09-28  
状态：实施中

## 决策

用户确认：备份与校验均使用**独立小窗口**（`WebviewWindow`），**不是**主窗口内模态对话框。

## 窗口职责

### 主窗口（main）
1. 文件浏览（盘符 / 目录 / 多选）
2. 列表中**隐藏** `.datavault`
3. 标记为备份盘
4. 按钮打开备份窗口、校验窗口
5. 不内嵌备份进度 / 校验结果大面板

### 备份窗口（backup）
1. 备份批次：源选择上下文、目标目录、开始备份、进度、结果
2. **添加受控文件**（异步哈希）
3. **建立备份索引**（异步扫描 + 哈希，可取消）
4. 标记备份盘入口可保留在主窗口；本窗聚焦复制与受控/索引

### 校验窗口（verify）
1. 受控文件：完整校验 / 快速校验
2. 备份批次：完整校验 / 快速校验
3. 结果列表（通过/失败/缺失/错误）

## Tooltip

- 风格：与「建立备份索引」相同，使用元素 `title` 中文说明。
- 批次校验：无 tooltip，或极简（例如「完整校验所选批次」）；**禁止**「头/尾 64KB」「旧路径」类文案。

## 异步

沿用 controlled-job 模式：后台线程 + progress/finished 事件。备份与校验同样不得阻塞 UI。

## 构建

`vcvars64.bat`（VS2022）后执行：

```text
npm run tauri build -- --no-bundle
```

## 打开方式（实现后）

- 主窗口标题栏/工具栏「备份」「校验」
- 若窗口已存在则聚焦并刷新上下文，否则 `new WebviewWindow(...)`
