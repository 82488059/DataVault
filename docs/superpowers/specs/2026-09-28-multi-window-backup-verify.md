# 多窗口：高级校验 / 高级备份

日期：2026-09-28  
状态：**现行**（主窗口为中心；高级校验 / 高级备份为独立辅助窗）

## 决策（现行）

1. **主窗口**完成浏览、标记为受控、批次备份、建立备份索引、范围/受控/批次校验。
2. **下方「状态」面板**统一展示多任务进度与校验结果（通过/失败/缺失/错误）。
3. **高级校验**（`batches` / `BatchManageApp`）：按目录校验 + 批次表多选校验。
4. **高级备份**（`adv-backup` / `AdvancedBackupApp`）：双栏源/目标备份。

历史「独立 backup/verify 窗」已撤销；现独立窗为高级能力，不替代主窗。

## 主窗口职责

1. 文件浏览；隐藏 `.datavault`；**标记为受控**（仅盘符根）
2. 列表列：**名称 / 大小 / 受控 / 数量**
3. **备份批次**：设源 / 设目标 / 可选批次名 / 开始备份
4. **建立备份索引**（单一按钮）：勾选→索引所选；可先标记未受控盘；已受控跳过
5. **校验**：当前勾选（仅已受控）；盘符列表勾选受控盘=全盘；批次校验
6. **状态面板**：多 job；中文标签；当前文件进度；取消；四态结果筛选
7. 入口：**高级校验**、**高级备份**

## 高级校验

- 仅显示已标记受控盘及受控路径
- 按目录：快速/完整校验勾选路径下受控项
- 按批次：批次号/时间/文件数/盘符；多选快/完整校验
- 结果四态与主窗一致

## 高级备份

- 左多选源、右单选受控盘/子目录；可选批次名称
- 目标未标记时可确认标记为受控后继续
- 列表列同主窗

## Tooltip

主要按钮 `title` 中文；不含头/尾 64KB 旧文案。

## 异步

controlled / backup / verify / dir-counts Job：后台 + progress/finished；UI 以状态面板为准。

## 构建

强制 VS2022 `vcvars64`（并保证其 `link.exe` 优先于 VS2017）：

```text
npm run tauri build
# 若 WiX/bundle 失败：
npm run tauri build -- --no-bundle
```
