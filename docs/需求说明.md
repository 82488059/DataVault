# 需求说明

## 产品目标

资源管理器式浏览本机磁盘；将目标盘**标记为受控**；在**主窗口**完成**批次备份**、**建立备份索引**与**完整/快速/范围/批次校验**。长任务在下方**多任务状态面板**异步展示；校验结果统一为**通过 / 失败 / 缺失 / 错误**四态并可筛选。

详细设计见：
- [多窗口 UI 规格](./superpowers/specs/2026-09-28-multi-window-backup-verify.md)
- [备份盘受控文件设计](./superpowers/specs/2026-09-28-backup-disk-controlled-files-design.md)（已批准）

## 窗口与功能

### 主窗口 — 文件浏览
- 盘符列表、进入/返回、多选、权限错误提示。浏览工具区：「盘符」「上级」「刷新」与路径、全选等同区。
- 列表列：**名称 / 大小 / 受控 / 数量**（已去掉「类型」「标记」列）。目录「数量」为受控文件数/总文件数（异步 `start_dir_file_counts`）。
- **隐藏**名为 `.datavault` 的目录。
- 对受控盘显示「受控盘」徽章；「**标记为受控**」（**仅盘符根**，例如 `E:\`；不可对子目录标记）。底层 API 仍为 `mark_backup_disk` / `is_backup_disk`。
- 条目显示绿色「受控」徽章（对照 `vault.db`：文件精确匹配；目录在其下存在受控文件时标记）。
- **备份 / 受控索引 / 校验均在主窗口**；标题行提供「高级校验…」「高级备份…」入口。
- **建立备份索引**（单一按钮，合并原「添加受控文件」）：勾选文件/目录则仅索引所选；勾选未标记盘符时可确认后先标记再索引；已受控跳过。
- **校验**直接使用当前勾选（仅已受控；未勾选则全部受控）；盘符列表勾选受控盘符亦可；非受控盘符不启用；批次校验。
- **状态面板**（主窗下方）：多任务并行列表（中文任务标签），展开见进度条、当前文件、取消；完成后内嵌校验四态摘要。无单独顶栏「取消」；少用瞬时成功/进度横幅。

### 备份 / 受控 / 索引（主窗口侧栏）
- **备份批次**：设源/设目标、可选批次名称、开始备份；进度进状态面板。
- **设为目标目录**：勾选一个目录指定目标；未勾选时用当前浏览目录。
- **建立备份索引**：见上；后台可取消。
- 浏览列表支持**全选 / 取消全选**。

### 校验（主窗口）
- **受控文件**：完整校验（`md5`）、快速校验（`fast_md5`）。
- **按勾选校验**：仅已受控项；盘符列表勾选受控盘=该盘全部受控。
- **备份批次**：选择批次后完整/快速校验。批次 ID 默认本地 ``YYYYMMDDHHmmss``，可自定义名称。
- **结果四态**：通过 / 失败 / 缺失 / 错误（`pass` / `fail` / `missing` / `error`）；计数按钮可点选筛选明细。批次校验与受控校验对齐同一四态模型。

### 高级校验窗口（独立，`batches`）
- 从主窗口「高级校验」打开。
- **按目录校验**：仅列出受控盘及含受控文件的路径；列同主窗（名称/大小/受控/数量）；勾选后快速/完整校验。
- **按批次校验**：表列批次号、时间、文件数、盘符；多选后快速/完整校验。
- 结果区同样四态筛选。可与主窗任务并行。

### 高级备份窗口（独立，`adv-backup`）
- 从主窗口「高级备份」打开。
- 双栏：左侧多选源（排除已标记受控盘作为源）；右侧单选受控盘或其子目录为目标；可选批次名称；未标记目标盘可确认后标记为受控再备份。
- 列表列：名称 / 大小 / 受控 / 数量。

### 悬停提示（tooltip）
- 主要按钮使用 HTML `title` 提供清晰中文说明。
- **禁止**出现「头/尾 64KB」「旧路径」等文案。

### 异步任务
- 登记/索引、备份复制、校验均走后台线程 + 进度/完成事件。
- 任务在状态面板以中文标签展示（如「备份」「登记受控」「完整校验」「快速校验」「批次完整校验」「批次快速校验」）。
- **取消**放在对应任务展开区；支持多任务并行（视类型）。

## 备份盘与受控文件（摘要）

- 盘根 `.datavault/disk.json`：`is_backup_disk=true`、`app=DataVault`（产品文案称**受控盘**）。
- `.datavault/vault.db` 表 `controlled_files`：含 `md5`、`fast_md5`、抽样参数等。
- FastMD5：默认每 100MB 块取前 10%，含余块；参数入库。

## 非目标（本阶段）
- 若 WiX/NSIS 不可用则不强求 MSI；以 `--no-bundle` 的 `datavault.exe` 为底线交付。
