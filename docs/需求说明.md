# 需求说明

## 产品目标

资源管理器式浏览本机磁盘，备份到目标盘，用完整/抽样 MD5 校验。

## 功能

### 浏览
盘符列表、进入/返回、名称/类型/大小、多选、权限错误提示。

### 备份
指定目标目录、递归复制、写批次元数据、允许部分成功。

### 完整 MD5
整文件标准 MD5（32 位小写十六进制）。

### 抽样 / 快速 MD5
1. size ≤ 64KB：整文件
2. 64KB < size ≤ 128KB：头 64KB + 剩余尾部
3. size > 128KB：头尾各 64KB
4. 追加文件大小十进制 ASCII 再算 MD5

### 校验 UI
完整校验 / 快速校验，基于备份批次展示通过/失败。
