# 需求说明

## 产品目标

资源管理器式浏览本机磁盘；将目标盘标记为**备份盘**；登记**受控文件**并写入盘上 SQLite；用**完整 MD5**与**FastMD5（分块抽样）**校验完整性。

详细设计见：[2026-09-28 备份盘受控文件设计](./superpowers/specs/2026-09-28-backup-disk-controlled-files-design.md)（已批准）。

## 功能

### 浏览
盘符列表、进入/返回、名称/类型/大小、多选、权限错误提示；对备份盘显示标识。

### 备份盘
- 盘根存在 `.datavault/` 且 `disk.json` 中 `is_backup_disk=true`、`app=DataVault` 即为备份盘。
- 支持「标记为备份盘」：创建 `.datavault/disk.json` 与 `.datavault/vault.db`。

### 受控文件
- 在备份盘上将文件加入受控清单（`controlled_files`）。
- 登记时计算并保存：`size`、`mtime`、完整 `md5`、`fast_md5`，以及 `sample_ratio`（默认 0.10）、`sample_chunk_mb`（默认 100）。

### 完整 MD5
整文件标准 MD5（32 位小写十六进制）。

### FastMD5（快速 / 抽样）
1. 按 `sample_chunk_mb`（默认 100MB，实现按 100×1024² 字节）分块；
2. **含最后不足一块的余块**；
3. 每块只取前 `sample_ratio`（默认 10%）字节，按块顺序喂入同一 MD5；
4. 所用比例与块大小写入该行元数据，校验时按登记参数重算。

### 校验 UI
- **完整校验**：对照库中 `md5`。
- **快速校验**：对照库中 `fast_md5`（用该行抽样参数）。
- 展示通过 / 失败 / 缺失 / 错误。

### 非目标（本阶段）
- 不做 MSI / 安装包打包。
- 旧「头尾 64KiB + 大小 ASCII」快速算法不再用于受控文件校验（见设计文档）。
