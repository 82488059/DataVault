# 需求说明

## 产品目标

资源管理器式浏览本机磁盘；将目标盘标记为**备份盘**；在**主窗口**完成**批次备份**、**受控文件登记/索引**与**完整/快速/范围/批次校验**。长任务异步执行，界面不卡死；校验结果在主窗独立面板展示。

详细设计见：
- [多窗口 UI 规格](./superpowers/specs/2026-09-28-multi-window-backup-verify.md)
- [备份盘受控文件设计](./superpowers/specs/2026-09-28-backup-disk-controlled-files-design.md)（已批准）

## 窗口与功能

### 主窗口 — 文件浏览
- 盘符列表、进入/返回、名称/类型/大小、多选、权限错误提示。
- **隐藏**名为 `.datavault` 的目录（不出现在列表中）。
- 对备份盘显示标识；支持「标记为备份盘」（**仅盘符根目录**，例如 `E:\`；不可对子目录标记）。
- 列表在备份盘上**显示条目是否已受控**（对照 `vault.db`：文件精确匹配；目录在其下存在受控文件时标记）。
- **备份 / 受控 / 索引 / 校验均在主窗口**（不再打开独立备份/校验窗）。
- **添加受控文件**、**建立备份索引**：须先勾选文件/目录，未勾选时按钮禁用。
- **按目录/文件范围校验**、受控校验、批次校验；**校验结果独立面板**（主窗下方专用区域，不与浏览/操作区混排）。

### 备份 / 受控 / 索引（主窗口侧栏）
- **备份批次**：确认/调整源路径、指定目标备份目录、开始备份、显示进度与结果。
- **设为目标目录**：支持**勾选一个目录**指定目标；未勾选目录时使用当前浏览目录（亦可手填路径）。
- **添加受控文件**：**须先勾选文件/目录**（未勾选时按钮禁用）；将勾选的备份盘路径登记到 `vault.db`（后台算 MD5 / FastMD5）。**已在 vault.db 中的文件跳过，不重复计算哈希。**
- **建立备份索引**：**须先勾选文件/目录**（未勾选时按钮禁用）；扫描当前备份盘；**仅对尚未受控的文件**计算并写入哈希（已受控跳过；后台任务，可取消）。
- 浏览列表**显示是否已受控**（对照 vault.db）。
- 浏览列表支持**全选 / 取消全选**（与主窗口一致；表头复选框 + 工具栏「全选」「清空选择」）。

### 校验（主窗口）
- **受控文件**：完整校验（对照 `md5`）、快速校验（对照 `fast_md5`）。列表**只显示 vault.db 已登记项**。
- **按目录/文件选择范围**：在备份盘上勾选目录或文件 →「应用到校验范围」，仅校验其中**已受控**的项；未受控不出现在可选文件列表与校验结果中。范围列表面板下方操作区提供「快速校验」「完整校验」（与受控区同布局），可先应用勾选范围再校验；上方工具栏单行显示。
- 未限定范围（未勾选）时校验**全部**受控文件。
- **备份批次**：选择批次后完整/快速校验。
- **校验结果独立面板**：通过 / 失败 / 缺失 / 错误等结果列表显示在**主窗口下方专用区域**，不与浏览 / 操作区混排；任务异步，可取消。

### 悬停提示（tooltip）
- 主要按钮使用 HTML `title` 提供清晰中文说明（风格与「建立备份索引」一致）。
- **批次校验**按钮：可不加 tooltip，或仅用简短提示（如「对所选批次做完整校验」）；**禁止**出现「头/尾 64KB」「旧路径」等文案。

### 异步任务
- 登记受控、建立索引、备份复制、校验计算均走后台线程 + 进度/完成事件，避免 UI 冻结。
- 同类重任务互斥或可取消（与现有 controlled-job 模式一致或扩展）。

## 备份盘与受控文件（摘要）

- 盘根 `.datavault/disk.json`：`is_backup_disk=true`、`app=DataVault`。
- `.datavault/vault.db` 表 `controlled_files`：含 `md5`、`fast_md5`、抽样参数等。
- FastMD5：默认每 100MB 块取前 10%，含余块；参数入库。

## 非目标（本阶段）
- 不做 MSI / 安装包打包（仅 `--no-bundle` 产物）。
