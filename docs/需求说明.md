# 需求说明

## 产品目标

资源管理器式浏览本机磁盘；将目标盘标记为**备份盘**；在独立窗口中完成**批次备份**、**受控文件登记/索引**与**完整/快速校验**。长任务异步执行，主界面与各窗口不卡死。

详细设计见：
- [多窗口 UI 规格](./superpowers/specs/2026-09-28-multi-window-backup-verify.md)
- [备份盘受控文件设计](./superpowers/specs/2026-09-28-backup-disk-controlled-files-design.md)（已批准）

## 窗口与功能

### 主窗口 — 文件浏览
- 盘符列表、进入/返回、名称/类型/大小、多选、权限错误提示。
- **隐藏**名为 `.datavault` 的目录（不出现在列表中）。
- 对备份盘显示标识；支持「标记为备份盘」。
- 入口按钮打开**备份窗口**、**校验窗口**（非模态对话框，独立 `WebviewWindow`）。
- 主窗口**不**承载备份进度、校验结果面板。

### 备份窗口 — 独立小窗口
- **备份批次**：确认/调整源路径、选择目标备份目录、开始备份、显示进度与结果。
- **添加受控文件**：将勾选（或传入）的备份盘路径登记到 `vault.db`（后台算 MD5 / FastMD5）。
- **建立备份索引**：扫描当前备份盘全部文件并写入索引（后台任务，可取消）。
- 可从主窗口带入当前选择与路径上下文。

### 校验窗口 — 独立小窗口
- **受控文件**：完整校验（对照 `md5`）、快速校验（对照 `fast_md5`）。
- **备份批次**：选择批次后完整/快速校验。
- 展示通过 / 失败 / 缺失 / 错误等结果列表。

### 悬停提示（tooltip）
- 主要按钮使用 HTML `title` 提供清晰中文说明（风格与「建立备份索引」一致）。
- **批次校验**按钮：可不加 tooltip，或仅用简短提示（如「对所选批次做完整校验」）；**禁止**出现「头/尾 64KB」「旧路径」等文案。

### 异步任务
- 登记受控、建立索引、备份复制、校验计算均走后台线程 + 进度/完成事件，避免 UI 冻结。
- 同类重任务互斥或可取消（与现有 controlled-job 模式一致或扩展）。

## 备份盘与受控文件（摘要）

- 盘根 `.datavault/disk.json`：`is_backup_disk=true`、`app=DataVault`。
- `.datavault/vault.db` 表 `controlled_files`：含 `md5`、`fast_md5`、抽样参数等。
- FastMD5：默认每 100MB 块取前 10%，含余块；参数入库。

## 非目标（本阶段）
- 不做 MSI / 安装包打包（仅 `--no-bundle` 产物）。
